# DriFly Offline Map Packs

Public release distribution repository for DriFly 100% offline map packs (vector tiles, offline geocoder, and compact road routing graphs).

- **Vector Tile Schema & Tooling:** [Protomaps](https://protomaps.com/) / PMTiles (BSD-3-Clause).
- **Fonts / Glyphs:** Noto Sans (SIL Open Font License 1.1).

Releases in this repository contain compiled map pack archives (*-pack-v*.zip) and manifest.json metadata consumed by the DriFly Android application.
